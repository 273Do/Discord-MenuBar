## Motivation

Discord is always running, but I found it comes with a few drawbacks:

- It occupies screen space even when not actively used
- Checking status or messages can easily interrupt focus
- Its rich feature set can be distracting when you just need the basics

To address this, I built this app to bring only the essential features into the macOS menu bar,
allowing you to stay connected without disrupting your workflow.

## Tech Stack

- SwiftUI
- macOS MenuBarExtra API
